# Tasks

One folder per non-trivial task: `NNN-<slug>-YYYY-MM-DD/`, holding `plan.md` (written upfront by the
[task-planner agent](../../.claude/agents/task-planner.md)), optional `notes.md` (operator feedback
captured during execution), and `report.md` (written at finalize).

`NNN` is a zero-padded incrementing counter. The lifecycle is owned by the
[task-flow skill](../../.claude/skills/task-flow/SKILL.md).
